**MOVESET SECTION**:

The following changes have been made to the moves below:

* Replaced one of the default finishers to an attack from 358/2 Days.
* Flame Juggle: The knock-up effect has been removed. Axel now hangs for less time in the air. Combo window has increased.
* Aerial Shred: Combo window starts earlier.
* Flame Windmill: Hitbox size has been increased.
* Disorder: Lowered the revenge value.
* Eruption: Lowered the revenge value. Changed the last hit in the sequence from Fire type to Special type.
* Fire Wall: Hitbox size increase.
* Meteor Slam: Hitbox size increase.
* Axel's attacks now interpolate back into his idle animation correctly.
* Changed Axel's deflecting animation to be his animation from 358/2 Days.
* Removed free-movement from most of Axel's attacks. Control over him should feel tighter.
* Swapped the order of Axel's default air finishers.
